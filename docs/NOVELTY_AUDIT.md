# SIH Novelty Audit & Feature Classification — Tribal Scholar AI

This document presents an honest technical audit classifying all platform features into **FOUNDATIONAL**, **ENHANCEMENT**, or **DIFFERENTIATOR** categories to ensure transparent, non-overclaimed evaluation during SIH 2026 jury presentations.

---

## Feature Classification Matrix

| Feature | Category | Rationale & Ecosystem Comparison |
| :--- | :--- | :--- |
| **Scholarship & Fellowship Catalog** | `FOUNDATIONAL` | Standard capability available in existing national/state portals (e.g. NSP, DigiLocker, State Portals). |
| **Online Application Form Submission** | `FOUNDATIONAL` | Standard portal workflow for digital application submission. |
| **Direct Benefit Transfer (DBT) Status Tracking** | `FOUNDATIONAL` | Standard PFMS integration capability present in government digital schemes. |
| **Basic Profile-Based Search** | `FOUNDATIONAL` | Basic database query filtering by state, category, or income limit. |
| **AI Scholarship Matching Engine** | `ENHANCEMENT` | Multi-factor weighted match score (% match) evaluating ST category, income, degree level, and score. |
| **Explainable Eligibility Engine** | `ENHANCEMENT` | Translates complex scheme eligibility rules into natural language checkmarks (✓ Criteria Met vs ⚠ Action Required). |
| **Document OCR & Format Validation** | `ENHANCEMENT` | Server-side MIME validation, completeness checking, and text extraction on uploaded certificates. |
| **Voice & Multilingual AI Assistant** | `ACCESSIBILITY ENHANCEMENT` | Natural language interface over 7 regional languages with Web Speech API integration and simple explanation mode. |
| **AI Deficiency Repair Copilot** | `DIFFERENTIATOR` | Interactive 5-step guided resolution (**DETECT → EXPLAIN → REPAIR → RECHECK → RESOLVE**) for name format variations and expired documents. |
| **Scholarship Application Digital Twin** | `DIFFERENTIATOR` | Live state machine rendering stage timeline, responsible authority, current blocker, dependency, student action required, and transition history. |
| **Scholarship Process Intelligence Engine** | `DIFFERENTIATOR` | Ministry-level intelligence loop analyzing queue accumulation, average processing durations vs benchmarks, root cause deficiency patterns, and preventive recommendations. |
